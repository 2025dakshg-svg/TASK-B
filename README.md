# Secret Agent Hacker Terminal: Hack the Matrix (Not Really)

A retro green-screen hacker terminal with falling Matrix-style code, fake hacking tools, sound effects, and a hidden cipher mini-game. Nothing here hacks anything real. It was built for the AI Coding Lab (Unit 3: AI Applications).

## How to Play
1. Open the live link and click anywhere on the page once so sound can play.
2. Click **SCAN**, **DECRYPT**, or **UPLOAD** to run a fake hack tool.
3. Watch the progress bar fill, listen for the beeps, and read the messages in the terminal log at the bottom.
4. Enter the secret code (see below) to unlock the hidden game.

## Secret Features
- **Konami Code unlock:** Press **↑ ↑ ↓ ↓ ← → ← → B A** on your keyboard to open the hidden cipher mini-game.
- **Cipher Mini-Game:** A secret message is scrambled with a Caesar cipher. Guess the shift (0-25) to decode it. Hint: it's a small number!
- **Wrong guesses show what you decoded:** Each wrong shift reveals a different scrambled version, so you can work out the right answer.
- **Built-in tests:** The code includes `console.assert()` checks for the cipher logic. Press F12 to open the Console and see them run.
